# FaceSwapPro Free Turbo

Personal ZeroGPU worker automatically created by the FaceSwapPro Android app.

The worker uses SimSwap under its CC BY-NC 4.0 license for non-commercial personal experimentation. FaceSwapPro adds a secret application gate so an arbitrary visitor cannot trigger renders through the API without the per-install secret.
